# Faria Birthday Website

Static birthday surprise website, ready for free hosting.

## Edit the wish

Open `index.html` and replace the text inside:

```html
<p id="wishText">...</p>
```

## Free hosting

Upload this whole folder to any static host:

- Netlify: drag the folder into Netlify Drop.
- Vercel: import the folder as a static project.
- GitHub Pages: push the folder to a repository and enable Pages.
- Cloudflare Pages: connect a repository and deploy.

No build step is required. The entry file is `index.html`.
